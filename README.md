# PVC Equipment Telegram Bot

Базова версія Telegram-бота для безкоштовного бронювання обладнання Пластового вишкільного центру.

## Що вже реалізовано

- 7 позицій обладнання з початковими залишками.
- Бронювання кількох різних позицій в одній заявці.
- Вибір кількості кнопками − / +.
- Вибір дати та часу.
- Мінімум 3 дні до дати отримання.
- Отримання/повернення: Пн–Пт, 11:00–17:00, крок 30 хв.
- Перевірка доступності на весь період.
- Ім'я, телефон, назва заходу.
- Обов'язкова згода з правилами.
- Підтвердження/відхилення адміністратором.
- Зміна адміністратором дати й часу отримання та повернення.
- Ручна фіксація фактично виданої кількості.
- Ручна фіксація фактично повернутої кількості та стану кожної позиції.
- Пошкоджене/не повернуте обладнання не повертається в доступний залишок.
- Нагадування за 1 день до отримання і повернення.
- SQLite база даних.

## Важливо

Токен Telegram-бота НЕ потрібно записувати в код. На сервері він має бути змінною середовища `BOT_TOKEN`.

Так само `ADMIN_ID` — Telegram ID єдиного адміністратора.

## Запуск локально для тесту

1. Створити віртуальне середовище Python.
2. Встановити залежності:
   `pip install -r requirements.txt`
3. Створити змінні середовища з `.env.example`.
4. Запустити:
   `python bot.py`

## Railway

Створіть новий сервіс з цього проєкту і додайте Variables:

- `BOT_TOKEN`
- `ADMIN_ID`

Start Command:
`python bot.py`

База SQLite зберігається у файлі, тому для бойового використання на Railway надалі бажано винести базу в PostgreSQL або підключити persistent volume. Це буде окремим кроком після тестування логіки.


## Поточний статус

Це перша робоча версія для тестування основного користувацького сценарію та базового адмінського процесу.
Перед бойовим запуском ми окремо доповнимо й протестуємо повний адмінський розділ: керування довідником обладнання, ручне бронювання та повний інтерфейс історії.
